# Кто тут, блядь, главный?

Адаптивный сатирический управленческий тест на чистом HTML, CSS и JavaScript. Никаких сборок, внешних API, аналитики, регистрации или сохранения даты рождения. Результат рассчитывается в браузере; астрология влияет только на развлекательный текст.

## Локальный запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```sh
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000> в папке проекта.

## Проверка

```sh
npm test
```

Тесты проверяют 12 вопросов, достижимость всех архетипов, фиксированное разрешение ничьей, границы знаков и отсутствие пустого результата.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий `FeklaMalko/who-is-the-boss` и загрузите файлы проекта в ветку `main`.
2. В настройках репозитория откройте Settings → Pages и выберите GitHub Actions в поле Build and deployment → Source.
3. Workflow `.github/workflows/pages.yml` запускает проверки и публикует корень проекта в Pages при push в `main`.
4. После успешного workflow сайт будет доступен по адресу `https://feklamalko.github.io/who-is-the-boss/`.
